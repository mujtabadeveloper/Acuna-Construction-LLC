# Acuna Construction LLC

Static HTML/CSS/JavaScript website, including the latest rounded, smaller header logo.

## GitHub
Extract this ZIP and upload its contents to the root of your repository. Keep index.html and assets/ together.

## Preview
Open index.html in your browser, or run python -m http.server 8000 in this folder. No installation or build is required.

## Hosting
Use a static website host. For Vercel select Other, leave the build command empty, and use the repository root as the output directory.

## Contact form
The form prepares an email using the visitor's email application; it does not use a backend.

Home photos are illustrative. Fonts use Google Fonts and require an internet connection.
